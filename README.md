# LinkedIn Post Media

Public image assets for approved LinkedIn educational posts.

- Image files are stored under `media/` and named with the post ID.
- Only finished, approved images should be made public here.
- The original drafts, private email approvals, Google Sheet, and API tokens are **not** stored in this repository.
- Direct image URLs use `https://raw.githubusercontent.com/hassanr1778062-spec/linkedin-post-media/main/media/<post-id>.png` (or the matching image extension).

This public repository is used only as a media source for a separate approval-gated posting workflow.
